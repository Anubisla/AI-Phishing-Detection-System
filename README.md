# AI-Based Phishing Detection System

A phishing detection system built using Python, Flask, and machine learning techniques to identify suspicious URLs.

## Features

- Detect suspicious URLs
- Machine learning-based classification
- Simple web interface
- URL safety prediction

## Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- HTML/CSS

## Project Status

Currently under development.
